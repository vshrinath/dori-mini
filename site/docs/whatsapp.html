Everything else happens inside a live session with Claude or Codex. This is the exception — text a dedicated number and it still files what you send.

What it actually does.

Two things, and nothing else.

Anything you send gets filed

A link, a photo of a receipt, a quick note — handled exactly as a pasted link or dropped file would be in a normal chat. No AI decides where it goes; that's the same deterministic routing every other capture type uses. Anything ambiguous lands in your inbox rather than being filed wrong.

filed the moment it arrives

Real questions get real answers

Answered by looking things up in your vault — the same lookup scripts your agent already uses for recall, nothing more. A follow-up like "and when does it renew?" works too. A bare link with no question skips this entirely and just gets filed, with no AI call spent on it.

read-only

What it needs.

One extra step during setup, or any time after.

  1. A spare WhatsApp number. Not your real one — see why below. A second SIM, a WhatsApp-only number, or a number you already keep for exactly this kind of thing.
  2. A one-time scan. The installer — or listen-whatsapp.mjs --pair-only at any point after — shows a QR code in your terminal. Scan it from that number's WhatsApp under Linked Devices → Link a Device. Done once, ever, unless you log it out yourself.
  3. Optionally, something to answer questions. Claude Code or Codex, whichever you already have, replies on your existing subscription — no separate API key or bill. Say no and it still files everything; it just won't answer back.

Why this is safe.

Each of these is an actual constraint in the code, not a promise in this paragraph.

A dedicated number

Isolated from your real one on purpose. Nothing here ever touches the number people actually reach you on.

Direct messages only

Group chats are rejected before anything else runs — not discouraged, blocked in code.

Filing is always mechanical

No AI decides what happens to what you send. Same deterministic routing as every other capture type, every time.

Replies are read-only

The AI that answers can only look things up — three specific lookup scripts. It cannot write, edit, delete or run anything else.

Credentials are locked to you

The session file that keeps you paired is owner-only on disk, unreadable by any other account on the machine.

Cheap by design

A bare link or attachment never triggers an AI call. Only an actual question does, so nothing idle costs anything.

What it won't do.

The honest limits — same standard as the rest of these pages. If it isn't here, it doesn't do it.

No memory beyond the current back-and-forth

It recalls the last handful of messages in that conversation, not everything you've ever sent.

Not the official Business API

It connects the way the WhatsApp Web app does, via Baileys — unofficial, widely used, not built or run by WhatsApp. Fine for a personal number at normal volume; not for a large audience.

Replies can't take action

They answer from your vault. They can't file, move or resolve anything on your behalf.

No groups, full stop

If the number is ever added to one, messages from it are ignored entirely rather than partially handled.

Skip freely. This whole page describes an optional add-on. Nothing else in Dori Mini depends on it, and skipping it during setup changes nothing about how the rest works.

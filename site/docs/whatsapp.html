Two things, and nothing else: anything you send gets filed, by the same deterministic routing every other capture uses — and questions get answered from your vault, read-only. A bare link skips the AI entirely.

What it needs.

One extra step during setup, or any time after.

  1. A spare number. Not your real one — see why below.
  2. A one-time scan. The installer shows a QR code in your terminal. Scan it under Linked Devices → Link a Device. Done once, ever.
  3. Optionally, something to answer questions. Claude Code or Codex, on the subscription you already have. Say no and it still files everything.

Why this is safe.

Each one is a constraint in the code, not a promise in this paragraph.

A dedicated number

Nothing here touches the number people actually reach you on.

Direct messages only

Group chats are rejected before anything else runs. Blocked in code.

Filing is mechanical

No AI decides where what you send goes.

Replies are read-only

It can look things up. It cannot write, edit, delete or run anything.

Credentials locked to you

The pairing file is owner-only on disk.

Cheap by design

Only an actual question costs anything. Idle sits free.

What it won't do.

If it isn't here, it doesn't do it.

Remember much

The last handful of messages in that conversation, not your whole history.

Use the official Business API

It connects the way WhatsApp Web does, via Baileys. Fine for a personal number; not for an audience.

Take action

Replies answer. They can't file, move or resolve anything.

Touch groups, ever

Added to one, its messages are ignored entirely.

Skip freely. Nothing else in Dori Mini depends on this. Skipping it changes nothing about how the rest works.

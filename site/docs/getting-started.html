Getting started

It's installed.
Here's what to say.

No commands to learn. One rule, one first thing, then a list to steal from.

Not set up yet? One line, once.

macOS/Linuxcurl -fsSL https://mini.mydori.app/install.sh | sh
Windowsirm https://mini.mydori.app/install.ps1 | iex

The rule: start the message with Dori. That's the entire trigger.

The exception: links and files need no trigger. Paste a YouTube URL, drop in a PDF or a photo of a receipt, and it files itself.

Do one thing first.

Say this in whichever agent you wired up. Any YouTube link works.

Dori, store this YouTube link: https://youtu.be/hiYTq9xnkPw
~/dori-vault/yt/2026-08-24-blind-spots-to-big-bets.md
# Blind Spots to Big Bets Source · youtube.com/watch?v=hiYTq9xnkPw · 46:08 ## Summary ## Where founders misread the market ## The bet that changed the model ## Full transcript

About a minute later, that file is on your disk — searchable from then on. The headings are the video's own chapters, used as they are.

Everything else you can say.

Same shape as the line above. Fill in the brackets, or leave them.

Capture something

Dori, start a new project called [Name]

Scaffolds an empty folder. Attach files any time after.

Dori, create my profile: I'm [Name], [Role] at [Company]

Or drop in a CV and let it read that instead.

Dori, create a brand called [Name] — here's our site: [URL]

Reads the site and writes up positioning, voice and colours.

Dori, turn this into minutes

Paste a transcript with it. Attendees, decisions and action items, each with an owner.

Dori, add WhatsApp as a channel

Needs a spare number, never your main one. Why it's safe →

Ask it something

Dori, what did I decide about [topic]?

Empty the very first time. Capture a few things, then ask again.

Dori, who's [Name] from [Company]?

Uses your agent's own web search. Free, works today.

Dori, what are my tasks?

Open items from the real task store, sorted by due date.

Dori, add a task: [what] by [when]

Also fills itself from a meeting's action items once minutes exist.

Dori, what do I need to resolve?

Anything it couldn't confidently file, usually because it fits two projects.

Dori, anything new in my inbox folder?

What landed in the watched folder since you last looked.

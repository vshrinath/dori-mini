Memory for the agent
you already have — not another one to run.

Dori Mini is a local, portable mirror of Dori's capture-routing, search, and inbox logic — plain Node.js scripts your existing Claude Code, Codex CLI, or Antigravity session can call directly. No server, no account, no new subscription. 

$ curl -fsSL https://mini.mydori.app/install.sh | sh

Reads before it runs anything — clones the repo, then hands off to its own setup.sh for the rest.

No new subscription

Runs on the Claude/Codex/etc. plan you already pay for.

No hidden API spend

Search, routing, and indexing run locally — tokens only spent on real reasoning.

Plain files, yours

Everything it writes is Markdown on your own machine. No lock-in.

What it actually does

Not a guess at what Dori does — every script mirrors specific real source.

YouTube link→searchable transcript
PDF, DOCX, receipt photo→filed Markdown, or an expense row
Pasted meeting transcript→attendees, decisions, action items
"What did we agree with X?"→an answer, linked to source

What the install command actually does

One line, run once. Here's what happens behind it — nothing hidden.

$ curl -fsSL https://mini.mydori.app/install.sh | sh

✓ Node.js 24 found (installs it automatically if missing)
✓ npm dependencies installed (local search model, one-time)
✓ yt-dlp found (installs it automatically if missing)
✓ markitdown found (installs it automatically if missing)
? Path to your vault: [Enter = creates one for you]
✓ vault skeleton created
? Your name: (required — for meeting-attendee matching)
? Fathom API key (optional): [Enter to skip]
? Tavily API key (optional): [Enter to skip]
✓ wired into Claude Code
? Set up the WhatsApp channel? [y/N] (macOS only, optional)
? Set up morning/evening digests? [y/N] (macOS only, optional)
  1. Installs Node.js 24+ if you don't have it — via nvm, brew, or apt, whichever's available. The one real requirement; everything else is a plain script, nothing to compile.
  2. Installs its dependencies — standard open-source npm libraries, same as any Node project. The only one worth knowing about by size: a local search model (a few hundred MB, downloaded once, runs entirely on your machine — this is what makes "find that thing I was thinking about" work later, even when your wording doesn't match exactly). Search itself uses SQLite, which ships built into Node — nothing extra to install for that part.
  3. Installs yt-dlp and markitdown if missing — for pulling YouTube transcripts and converting documents, via brew or pip3, whichever's available.
  4. Asks where your vault lives — press Enter and it creates an empty one for you. This folder is the only thing that matters; everything else is disposable and rebuilds from it.
  5. Asks your name — the one required question. Used so meeting notes can automatically recognize and skip you when matching who attended.
  6. Asks for two optional API keys (Fathom, Tavily) — skip both if you don't have them. See "what's optional" below.
  7. Wires itself into your agent — Claude Code, Codex CLI, Antigravity, or Grok Build, whichever you already have. This is the only reason it needs to touch anything outside its own folder, and it's also the entire "interface" — there is no separate app or website to learn.
  8. Offers to pair the WhatsApp channel (macOS only) — say no and skip it entirely, or say yes and scan a QR code right there in the terminal. Runs on Baileys, an unofficial but widely used library for connecting your own WhatsApp account as a channel — not something built or run by WhatsApp itself. What it needs, and why it's safe →
  9. Offers to schedule morning/evening digests (macOS only) — a local summary page plus a desktop notification, at times you pick. Say no and run it by hand later any time instead.

Your vault, before and after

Your vault is your local home — five empty folders at first, filling in only as you actually use it.

By default it's created at ~/dori-vault (the ~ just means "your home folder") — open it in Finder or Explorer any time and look around. It's not a database you need this tool to read.

Right after install
dori-vault/ ├── inbox/ ├── entities/ │ ├── people/ │ └── projects/ ├── projects/ ├── yt/ └── references/ └── clippings/
A week of normal use
dori-vault/ ├── inbox/ ├── entities/ │ ├── people/ │ │ └── priya-menon.md │ └── projects/ ├── projects/ │ └── acme-nonprofit/ │ └── meetings/ ├── yt/ │ └── 2026-08-24-the-core-argument.md ├── finances/ │ └── trips/denver-conference.md └── references/ └── clippings/

Every folder on the right came from something you just said in chat — nothing was scaffolded in advance. A new project folder, a new person file, a new trip ledger: each one is created the first time it's actually needed, and only after you'd recognize what it's for. The one exception is inbox/ — it's there from the start, and it's where anything ambiguous lands instead of being filed wrong. Ask "anything in my inbox?" any time to triage it.

✎
What's a Markdown file? A .md file is plain text with a few light symbols for structure (# for a heading, - for a bullet) — it opens in any text editor, and pastes cleanly into Word or Google Docs with formatting intact. It's used here because it's the cheapest format for an AI agent to read: no parsing overhead, no proprietary structure, just words — which is also why it's what most AI assistants already read and write natively. Try this first

Seven things to say right after setup — pick whichever matches something you'd genuinely do today.

"

"Dori, start a new project for me — here are the files."

Say it while attaching whatever you're already working on. It reads what's there and sets up a scoped project folder — search later stays inside that project, so results won't mix with unrelated work.

"

Paste a YouTube link — it reacts on its own, no "Dori" needed

You'll have a searchable transcript in your vault in under a minute — it also builds a small local HTML page you can click open and browse, no video download needed.

"

Drag in a PDF or a photo of a receipt — same thing, it just reacts

Watch it either convert to clean Markdown, or — if it looks like a bill — get proposed as an expense row. Not sure what it is? It asks, or leaves it in your inbox — "Dori, anything in my inbox?" any time to triage.

"

"Dori, turn this into minutes" (with a transcript pasted in)

Designed to minimize the work you do after a meeting — comes back as Attendees · Topics · Decisions Log · Action Items, each item tagged with who owns it.

Connect Fathom* instead and skip the pasting entirely. *Fathom is optional: fathom.video.

"

"Dori, who's Priya Menon from Acme?" (she just joined a meeting)

It looks them up and confirms before filing — and afterward you can ask things like "Dori, how many meetings have I had with Priya?" or "Dori, what did we discuss on August 15th?"

"

"Dori, what do I need to resolve?"

Lists what's sitting in your inbox — captures it couldn't confidently file on its own, usually because a new document could belong to more than one project. It's not a bug, it's a safeguard: rather than guess and file something in the wrong place, it holds it here and asks you. Nothing sits there silently — check any time, or just wait until it's mentioned. (Separately, "Dori, what are my pending tasks?" pulls your actual tracked to-dos — a different list from the inbox.)

"

"Dori, what did I decide about ___?" for something you actually discussed recently

It'll come back empty the very first time — that's expected. Capture a couple of things, then ask again.

Optional, skip freely
Fathom lets it pull meeting recordings straight from your account instead of you pasting a transcript. Tavily lets it look up context on a new meeting attendee. Neither is required for anything else here — every other feature works identically without them.
Optional, skip freely
"Dori, we need a brand for ___" sets one up — a company you work for, or one you're building. It starts with just a name and, if you give them, colors and fonts. The part that actually shapes writing is the guidelines underneath: open entities/brands/<slug>.md and write in the voice, positioning, and any real copy worth reusing — nothing fills that in on its own. Once it's there, "write this in the ___ voice" reads it before writing instead of guessing.

No lock-in

Uninstall it tomorrow, keep everything it made.

⇥
Delete this tool entirely and your vault — every transcript, every minutes doc, every ledger row — is still just a folder of Markdown files on your own disk. Nothing here locks content into a format only it can read. The two open-source tools it leans on for conversion are worth knowing by name, too: markitdown (documents → Markdown) and yt-dlp (YouTube transcripts) — both widely used, both auditable, neither controlled by this project.
